Copper 0.2.1 adds signed macOS distribution and separates the development app from your everyday workspace.

- macOS installers are Developer ID signed and Apple-notarized for Apple Silicon and Intel.
- Signed macOS releases can check for updates, download them, and restart when you choose. Windows and Linux continue to use manual installer updates.
- Copper Dev has its own identity, icon, and app data. Run it with `pnpm dev` while the installed Copper app remains available.
- The release pipeline verifies signatures, notarization, native SQLite, installer completeness, update metadata, and checksums before creating a draft.
- Includes the Electron and dependency security fixes made since 0.1.0.

If you use 0.1.0 or the older Tauri app, download this installer manually once. Install Copper in Applications on macOS. Keep a backup of your Vault; development should use a separate test Vault or a copy, not your everyday files.

Windows installers remain unsigned and may show SmartScreen. Linux packages remain available for x64 and ARM64. See [installation instructions](https://github.com/antick/copper/blob/v0.2.1/docs/INSTALL.md).
