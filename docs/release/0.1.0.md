Copper’s first release from this repository brings Notes and Tasks into one local workspace.

- Write Markdown with live preview, linked notes, backlinks, search, tags, and properties.
- Plan projects with issue lists and boards, priorities, labels, due dates, and custom workflows.
- Keep notes, projects, and issues as readable Markdown files on your computer. No account required.
- Use tabs, pinned projects, light and dark themes, and optional Git vault publishing.

## Downloads

Installers cover macOS Apple Silicon and Intel (DMG and ZIP), Windows x64 (EXE),
and Linux x64 and ARM64 (AppImage and DEB). Source archives are also available.
Read the [installation guide](https://github.com/antick/copper/blob/v0.1.0/docs/INSTALL.md)
to choose a file. `SHA256SUMS` covers all nine installers.

These early builds have no paid Apple or Microsoft publisher certificate.
macOS builds are ad-hoc signed, not notarized; Windows may show SmartScreen.
Updates are manual in this release. Back up your Vault before upgrading.

Legacy Tauri installations need a fresh installation. Saved task views,
dependencies, milestones, and note-checkbox ingestion are not included.

Website: https://copper.potion.sh
